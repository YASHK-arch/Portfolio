## 🚀 Key Projects

- **[RepoOwl](https://github.com/YASHK-arch/RepoOwl-extension)**: An AI-powered GitHub extension for issue triage and duplicate detection using LLMs and semantic similarity. *(Next.js, Node.js, Gemini, PostgreSQL)*
- **[NavNER-AI](https://github.com/YASHK-arch/NavNER-AI)**: AI logistics and accessibility intelligence platform designed for the North Eastern Region, featuring predictive disruption alerts. *(React, Leaflet, Node.js, MongoDB, Gemini)*
- **[OmniReceipt Parser](https://github.com/YASHK-arch/OmniReceipt-parser)**: Converts unstructured physical receipts into clean JSON data utilizing Google Gemini's multimodal capabilities. *(Next.js, TypeScript, Gemini)*
- **[VISION RUSH](https://github.com/YASHK-arch/VISION_RUSH-Deepfake-Detection-Engine)**: A deepfake detection engine built from scratch using a Vision Transformer (ViT-B/14) with a DINOv2 backbone. *(Python, PyTorch)*
- **[News Guru](https://github.com/YASHK-arch/News-Guru)**: A minimalist, ad-free news aggregator offering a clean reading experience. *(React, Tailwind, Express)*
- **[ShopKart BEL](https://github.com/YASHK-arch/ShopKart-BEL)**: A full-featured e-commerce platform handling end-to-end user journeys, from catalog browsing to cart management. *(MERN Stack)*
